# Parallel Brew Scheduler

A single-file tool for designing competition pour-over recipes on up to three drippers in parallel, and running them at the bar.

**Open it:** https://r31ghost.github.io/ParallelBrewScheduler/

This repository is a published copy of the tool (`index.html`). Recipes and presets are saved in your own browser; use the tool's export to back them up or move them between devices.
